# EventForge v1.8.1 — viewing-guide description focus

Extract into existing public_html and overwrite included files. No reinstall.

OpenAI description prompts now prioritize the event date, start time, TV channels and legal live streaming options. They avoid generic event hype, biographies, venue atmosphere and predictions. The single approved description remains capped at 100 words.

The existing inputs supply only the event name and date. The prompt therefore does not invent exact times, time zones, TV channels or streaming services; when those details are missing it directs readers to the official schedule and local viewing listings. This update does not add API web search or claim that schedules have been verified.

Existing approved descriptions remain saved. Click Regenerate Description and approve the new text to apply the new focus to future batches. Existing generated files are unchanged. Multi-domain rotation and all other generation behavior remain unchanged.
