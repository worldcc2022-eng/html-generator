# EventForge v1.6.1 — two-column Settings

Extract into existing public_html and overwrite included files. No reinstall.

On screens wider than 900px, OpenAI Connection and HTML Template stay in the left column; Title Templates and ID Templates stack in the right column. Below that width, the sections form one column in the same order. The template panels use the full available column width. All saving and generation behavior remains unchanged.

This cumulative update excludes config.php, install.php and storage files.
